# 🌿 Personal Portfolio Website

Welcome to the source code of my personal portfolio website! Built with a clean Studio Ghibli / forest aesthetic theme to showcase my background in Data Science and Artificial Intelligence.

## ✨ Features
- **About & Education:** Background as a 3rd-year B.Sc. Data Science & AI student at IIT Guwahati.
- **Technical Toolkit:** Highlighting proficiency in Python, R, SQL, Machine Learning tools, and LaTeX.
- **Verified Credentials:** Direct access to professional certificates (Cognitive AI, Google, IBM, IIT Guwahati x Coursera) and personal achievements.
- **Featured Projects:** Direct links to interactive machine learning and data science repositories.
